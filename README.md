# Calculadoras

Site feito com HTML, CSS e JavaScript para o trabalho de Desenvolvimento Web do curso de TADS.

## Calculadoras disponíveis

- **IMC (Índice de Massa Corporal):** calcula o IMC a partir do peso e da altura e mostra a classificação.
- **Taxa Metabólica Basal:** calcula quantas calorias o corpo gasta por dia em repouso, usando a fórmula de Harris-Benedict.
- **Salário Líquido:** calcula o salário líquido descontando INSS e IRRF, com as tabelas de 2026 (incluindo a isenção do IR para quem ganha até R$ 5.000).

## Como usar

Basta baixar os arquivos e abrir o `index.html` no navegador.

## Arquivos

- `index.html`: estrutura da página
- `style.css`: estilo da página
- `script.js`: cálculos
